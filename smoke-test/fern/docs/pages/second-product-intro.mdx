# Introduction to Second Product

Welcome to the second product! This page demonstrates the product switcher functionality.

## Overview

This is a simple page that exists to test the product switching feature. When you switch between products using the product dropdown, the navigation should use client-side routing for fast transitions.

## Features

- Fast product switching with client-side navigation
- Separate navigation structure per product
- Independent tabs and sections for each product

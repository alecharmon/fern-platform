## Implementation

Here's how to implement sdk usage for webhooks:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example webhooks sdk usage implementation
const result = await client.webhooks.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

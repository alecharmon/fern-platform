# Webhooks getting started

This guide covers getting started for the Webhooks API.

## Overview

Learn how to effectively use getting started patterns with the Webhooks API in your plant store application.

## Prerequisites

Before you begin, make sure you have:

- A valid API key
- The latest version of the SDK installed
- Basic understanding of REST APIs

## Implementation

Here's how to implement getting started for webhooks:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example webhooks getting started implementation
const result = await client.webhooks.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

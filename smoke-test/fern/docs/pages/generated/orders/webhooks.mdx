# Orders webhooks

This guide covers webhooks for the Orders API.

## Overview

Learn how to effectively use webhooks patterns with the Orders API in your plant store application.

## Prerequisites

Before you begin, make sure you have:

- A valid API key
- The latest version of the SDK installed
- Basic understanding of REST APIs

## Implementation

Here's how to implement webhooks for orders:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example orders webhooks implementation
const result = await client.orders.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

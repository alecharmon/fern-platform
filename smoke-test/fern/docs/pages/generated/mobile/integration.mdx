# Mobile integration

This guide covers integration for the Mobile API.

## Overview

Learn how to effectively use integration patterns with the Mobile API in your plant store application.

## Prerequisites

Before you begin, make sure you have:

- A valid API key
- The latest version of the SDK installed
- Basic understanding of REST APIs

## Implementation

Here's how to implement integration for mobile:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example mobile integration implementation
const result = await client.mobile.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

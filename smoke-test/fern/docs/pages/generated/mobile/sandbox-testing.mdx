# Mobile sandbox testing

This guide covers sandbox testing for the Mobile API.

## Overview

Learn how to effectively use sandbox testing patterns with the Mobile API in your plant store application.

## Prerequisites

Before you begin, make sure you have:

- A valid API key
- The latest version of the SDK installed
- Basic understanding of REST APIs

## Implementation

Here's how to implement sandbox testing for mobile:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example mobile sandbox testing implementation
const result = await client.mobile.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

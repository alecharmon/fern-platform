## Implementation

Here's how to implement configuration for invoices:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example invoices configuration implementation
const result = await client.invoices.list({
  limit: 100,
  cursor: 'next-page-token',
```

## Implementation

Here's how to implement sdk usage for payments:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example payments sdk usage implementation
const result = await client.payments.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

## Overview

Learn how to effectively use examples patterns with the Cards API in your plant store application.

## Prerequisites

Before you begin, make sure you have:

- A valid API key
- The latest version of the SDK installed
- Basic understanding of REST APIs

## Implementation

Here's how to implement examples for cards:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example cards examples implementation
const result = await client.cards.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

Before you begin, make sure you have:

## Implementation

Here's how to implement advanced usage for team:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example team advanced usage implementation
const result = await client.team.list({
  limit: 100,
```

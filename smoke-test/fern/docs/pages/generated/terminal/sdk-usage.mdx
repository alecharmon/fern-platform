Before you begin, make sure you have:

- A valid API key

## Implementation

Here's how to implement sdk usage for terminal:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example terminal sdk usage implementation
const result = await client.terminal.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

# Oauth examples

This guide covers examples for the Oauth API.

## Overview

Learn how to effectively use examples patterns with the Oauth API in your plant store application.

## Prerequisites

Before you begin, make sure you have:

- A valid API key
- The latest version of the SDK installed
- Basic understanding of REST APIs

## Implementation

Here's how to implement examples for oauth:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example oauth examples implementation
const result = await client.oauth.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

# Oauth sdk usage

This guide covers sdk usage for the Oauth API.

## Overview

Learn how to effectively use sdk usage patterns with the Oauth API in your plant store application.

## Prerequisites

Before you begin, make sure you have:

- A valid API key
- The latest version of the SDK installed
- Basic understanding of REST APIs

## Implementation

Here's how to implement sdk usage for oauth:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example oauth sdk usage implementation
const result = await client.oauth.list({
  limit: 100,
  cursor: 'next-page-token',
});
```

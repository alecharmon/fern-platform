## Implementation

Here's how to implement api patterns for oauth:

```typescript
import { PlantStoreClient } from '@plant-store/sdk';

const client = new PlantStoreClient({
  apiKey: 'your-api-key',
});

// Example oauth api patterns implementation
const result = await client.oauth.list({
  limit: 100,
  cursor: 'next-page-token',
});
```
